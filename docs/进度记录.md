## 1. 项目是什么

**企业老板法律助手**——一个手机 H5：老板打字 / 拍照 / 传文件问任何法律问题，大模型识别并解答。
不预设问题类型（合同审查、法规检索、劳动纠纷都算）。

核心架构：手机 H5 → 混元视觉识别图片/文件 → **hy3** 解答（限额/失败自动切 **deepseek**，并标注"备用模型生成"）。
**V0.02 新增**：律师可上传法律条文/法规到「知识库」，模型解答时**优先引用**这些资料。

## 7. 接口速查（V0.02）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/chat` | 咨询；支持文字 / 图片 / 文件；优先引用知识库 |
| POST | `/api/kb/upload` | 上传知识库文件（多文件） |

| DELETE | `/api/kb/:name` | 删除指定知识库文件 |
| GET  | `/api/health` | 健康检查（含 keysReady） |
